# 🍓 Berry Fresh Articles (Knowledge & Cold-Chain Research Hub)

Pusat riset sains rantai dingin, edukasi nutrisi buah berry, dan artikel agrikultur berkelanjutan dalam ekosistem Berry Fresh.

---

## 🏛 Komponen
1. **`server/`:** Node.js Express 4.21 REST API dengan basis data MongoDB / Mongoose.
2. **`ui/`:** Aplikasi web pembaca artikel berbasis Vite, React, dan Material UI (MUI v6).

---

## 🏃 Menjalankan Aplikasi

### 1. Menjalankan Server API (Port 5000)
```bash
cd apps/articles/server
npm install
npm run dev
```

### 2. Menjalankan UI Pembaca Artikel (Port 5173)
```bash
cd apps/articles/ui
npm install
npm run dev
```

Aplikasi web pembaca artikel akan aktif di `http://localhost:5173`.
